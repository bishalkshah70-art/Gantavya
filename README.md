# Gantavya 🇳🇵

Gantavya is a trip planning and booking platform focused on Nepal. The idea is to make it easier for people to plan their trips, explore destinations, find accommodation, and manage their bookings in one place.

The name *Gantavya* means “destination” in Nepali.

## Features

- Explore destinations in Nepal
- Search and filter hotels, restaurants, and attractions
- Generate itineraries based on route and trip duration
- Manage bookings and trip details
- Test payments using eSewa and Khalti sandbox environments
- View trip information from one dashboard
- Admin panel for managing destinations and bookings

## Tech Stack

- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Caching:** Redis
- **Background Jobs:** BullMQ

## Getting Started

Clone the repository:

```bash
git clone https://github.com/bishalkshah70-art/gantavya.git
cd gantavya
```

The project is planned to have separate `frontend` and `backend` folders. Setup commands and environment variables may change as development continues.

## Project Status

Gantavya is currently in the planning and MVP development stage. Some features are planned and may not be implemented yet.
